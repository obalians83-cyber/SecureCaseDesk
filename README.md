# SecureCaseDesk 3.0

تطبيق أولي لإدارة القضايا والملفات، مبني باستخدام Python وFlet.

## محتويات المشروع

- `main.py`: كود التطبيق المرسل.
- `pyproject.toml`: إعدادات Flet وبيانات التطبيق.
- `requirements.txt`: المكتبات المطلوبة.
- `.github/workflows/build.yml`: بناء APK وWindows EXE عبر GitHub Actions.

## البناء السحابي

1. أنشئ مستودعاً على GitHub.
2. ارفع **محتويات** هذا المجلد إلى جذر المستودع، بما فيها المجلد المخفي `.github`.
3. افتح تبويب Actions.
4. اختر `SecureCaseDesk Cloud Build`.
5. اضغط `Run workflow` أو ادفع commit إلى فرع `main`.
6. بعد انتهاء المهمتين، افتح تشغيل workflow ونزّل:
   - `SecureCaseDesk-APK`
   - `SecureCaseDesk-Windows`

## التشغيل محلياً

```bash
python -m pip install -r requirements.txt
flet run main.py
```

## ملاحظات مهمة قبل الاستخدام الحقيقي

هذه الحزمة تنقل الكود المقدم إلى مشروع قابل للرفع والبناء، لكنها لا تعني أن التطبيق اجتاز اختباراً وظيفياً أو أمنياً شاملاً.

- يجب اختبار توافق إصدار Flet مع عناصر الواجهة المستخدمة في `main.py`. قد تتطلب بعض واجهات Flet تعديلات حسب الإصدار.
- بناء Windows ينتج مجلد تطبيق/ملفات تشغيل، وليس بالضرورة ملف Setup.exe.
- ميزة الذكاء الاصطناعي تتطلب إعداد متغيرات البيئة المناسبة. وضع Local يتطلب خدمة Ollama متاحة على عنوان يمكن للجهاز الوصول إليه.
- لا تضع مفاتيح API أو كلمات مرور داخل المستودع. استخدم GitHub Secrets عند إعداد خدمات خارجية.
- مفاتيح التشفير محفوظة حالياً بجانب بيانات التطبيق؛ هذا نموذج أولي وليس تصميماً آمناً لتخزين أسرار مؤسسي.
- لا تستخدم هذا الإصدار لمعالجة بيانات قضايا حقيقية أو حساسة قبل مراجعة أمنية مستقلة، واختبار الصلاحيات والنسخ الاحتياطي والاستعادة وإدارة المفاتيح.
